# Developing a HIPAA Compliant Application Using Localized Large Language Models to Identify and Replace Stigmatizing Language in Synthetic Clinical Notes
This was my junior year science research project. The problem was that in the medical notes written by clinicians, it was found that they would use stigmatizing language when writing about their patients in around 5% of all notes. Since hundreds of millions of notes are written every year and it is completely free to view such notes, this can affect millions of people. During this research project, I tested the F1-score between Phi-4, LLama 3.1, and Mistral. Here are the results:

Therefore, this application uses the Phi-4 model, although it does run much slower. This application is considered HIPAA compliant, as it does not rely on any API based LLMs, making it very secure in handling sensitive medical information.
